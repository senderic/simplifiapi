simplifiapi

Unofficial Python API for Quicken Simplifi — export your finances

Python 3.9+ MIT Licensed 98% Test Coverage
View on GitHub Documentation
CLI
Python
# Export transactions as CSV
$ simplifiapi --email you@example.com \
    --transactions --format csv

# Export all data as JSON
$ simplifiapi --token abc123 \
    --accounts --transactions --tags --categories

What you can do

💰

Accounts & Transactions

Fetch all your checking, savings, credit card accounts and their transactions with a single call.

📊

CSV or JSON Export

Output data as flat CSV files for spreadsheets, or full JSON for custom data pipelines.

🔒

MFA Support

Handles multi-factor authentication interactively. Cache your token to skip MFA on subsequent runs.

📦

Lightweight & Zero Bloat

Only two dependencies: requests and configargparse. Installs in seconds.

🔀

Automatic Pagination

Large datasets are automatically paginated — you get the full result, not just the first page.

🧪

Type Annotated

Full type hints throughout. Works with mypy, pyright, and your IDE for autocompletion.

Install in seconds

# Install
pip install git+https://github.com/senderic/simplifiapi

# Run it
simplifiapi --help
